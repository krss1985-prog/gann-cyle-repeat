# Gann Cycle Repeat Scanner v2

Streamlit app for scanning repeating Gann cycles with multi-window matching and composite overlays.

## Setup

1. Create and activate a virtual environment.
2. Install dependencies:

```
pip install -r requirements.txt
```

## Run

```
streamlit run app.py
```

## Notes

- Uses Yahoo Finance for price history.
- Default ticker list is in app.py.
